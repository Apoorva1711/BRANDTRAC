# BRANDTRACE REST API Reference

All protected endpoints require an `Authorization: Bearer <JWT>` header. Requests and responses use `application/json` unless otherwise specified.

---

## 1. Authentication Endpoints

### `POST /api/auth/register`
Register a new analyst account and create an organization tenant.
- **Body:** `{ name, email, password, organization }`
- **Response (201):** `{ success: true, token, user }`

### `POST /api/auth/login`
Authenticate existing analyst.
- **Body:** `{ email, password }`
- **Response (200):** `{ success: true, token, user }`

### `GET /api/auth/me` *(Protected)*
Fetch active authenticated user details.
- **Response (200):** `{ success: true, user }`

---

## 2. Brand Profiles

### `GET /api/brands` *(Protected)*
List all monitored brands in the user's organization.
- **Query Params:** `includeArchived` (boolean)
- **Response (200):** `{ success: true, count, brands: [...] }`

### `POST /api/brands` *(Protected, multipart/form-data)*
Create a new brand profile with optional logo upload.
- **Fields:** `name`, `legalName`, `description`, `websiteUrl`, `aliases`, `keywords`, `trustedDomains`, `logo` (file)
- **Response (201):** `{ success: true, brand }`

### `GET /api/brands/:id` *(Protected)*
Fetch single brand with live candidate and threat counts.
- **Response (200):** `{ success: true, brand }`

### `PUT /api/brands/:id` *(Protected, multipart/form-data)*
Update brand metadata or replace logo.
- **Response (200):** `{ success: true, brand }`

### `DELETE /api/brands/:id` *(Protected)*
Archive brand profile.
- **Response (200):** `{ success: true, message }`

---

## 3. Official Asset Registry

### `GET /api/assets` *(Protected)*
List trusted assets across organization.
- **Query Params:** `brandId`, `assetType`
- **Response (200):** `{ success: true, count, assets: [...] }`

### `POST /api/assets` *(Protected)*
Register trusted brand asset for exact match exclusion.
- **Body:** `{ brandId, assetType, identifier, url, platformOrStore, publisherName, notes }`
- **Response (201):** `{ success: true, asset }`

### `DELETE /api/assets/:id` *(Protected)*
Remove asset from trusted registry.
- **Response (200):** `{ success: true, message }`

---

## 4. Scan Execution

### `POST /api/scans` *(Protected)*
Initiate a synchronous candidate evaluation pipeline.
- **Body:** `{ brandId, scanType: 'both' | 'social' | 'app', source }`
- **Response (201):** `{ success: true, scan: { status, candidatesEvaluated, excludedCount, threatsFound, durationMs } }`

### `GET /api/scans` *(Protected)*
List scan execution history.
- **Query Params:** `brandId`, `status`, `page`, `limit`
- **Response (200):** `{ success: true, total, page, pages, scans: [...] }`

### `GET /api/scans/:id/results` *(Protected)*
Inspect findings and excluded candidates generated by a specific scan.
- **Response (200):** `{ success: true, scan, detections, excludedCandidates }`

---

## 5. Threat Detections

### `GET /api/detections` *(Protected)*
Query active threat findings with multi-criteria filtering.
- **Query Params:** `brandId`, `candidateType`, `riskCategory`, `status`, `search`, `page`, `limit`
- **Response (200):** `{ success: true, total, page, pages, detections: [...] }`

### `GET /api/detections/:id` *(Protected)*
Retrieve complete threat dossier including signal point breakdown, official asset comparisons, and notes timeline.
- **Response (200):** `{ success: true, detection, officialAssets, investigationNotes }`

### `PATCH /api/detections/:id/status` *(Protected)*
Update analyst review status.
- **Body:** `{ status: 'New' | 'Under Review' | 'Suspected Impersonation' | 'False Positive' | 'Resolved', note, falsePositiveReason }`
- *Note: `falsePositiveReason` or `note` is mandatory when declaring False Positive.*
- **Response (200):** `{ success: true, detection, auditNote }`

### `POST /api/detections/:id/notes` *(Protected)*
Append internal analyst notes to the case log.
- **Body:** `{ note: string }`
- **Response (201):** `{ success: true, note }`

---

## 6. Reports & Telemetry

### `GET /api/reports/detections.csv` *(Protected)*
Download sanitised CSV export of filtered detections (immune to formula injection).
- **Response:** `Content-Type: text/csv`

### `GET /api/reports/scans.csv` *(Protected)*
Download CSV summary of all scan executions.
- **Response:** `Content-Type: text/csv`

### `GET /api/health`
Public server health check.
- **Response (200):** `{ status: 'healthy', services: { database, detectionService } }`

### `GET /api/sources/health` *(Protected)*
Returns honest connectivity status for all configured adapters.
- **Response (200):** `{ success: true, sources: [...] }`

### `GET /api/dashboard/stats` *(Protected)*
Returns aggregated live metrics calculated from MongoDB records.
- **Response (200):** `{ success: true, stats: { totalBrands, totalAssets, totalCandidates, riskDistribution, ... } }`
